  • FMOne.mutation.burden.per.MB (Tumor Mutational Burden - TMB): This is the total number of mutations found per megabase of DNA. “FMOne” stands for FoundationOne, which is the specific FDA-approved genetic sequencing test the researchers used on these patients. This is the primary metric used in Figure 1d and 1e of the paper.

  • Neoantigen.burden.per.MB (Tumor Neoantigen Burden - TNB): This is a specific subset of the TMB. It only counts mutations that actually change a protein’s structure in a way that creates a new, visible target (an antigen) for the immune system to attack.

Therefore, we will proceed with the survival analysis using both subsets independently to determine their distinct predictive values.

Helper functions

# Convert a survdiff() chi-squared statistic to a p-value.
lr_p <- function(x) {
  pchisq(x$chisq, df = length(x$n) - 1, lower.tail = FALSE)
}

# Draw a Kaplan–Meier curve with confidence bands, a risk table, and p-value.
km_plot <- function(fit, title, p) {
  ggsurvfit(fit, linewidth = 1) +
    add_confidence_interval() +
    annotate(
      "text",
      x = Inf, y = Inf,
      label = paste0(
        "Log-rank p = ",
        format.pval(p, digits = 2, eps = 0.001)
      ),
      hjust = 1.1, vjust = 1.4
    ) +
    add_risktable(
      risktable_stats = c("n.risk", "cum.event"),
      stats_label = c("At risk", "Events")
    ) +
    scale_ggsurvfit() +
    labs(
      title = title,
      x = "Overall survival (months)",
      y = "Overall survival probability",
      color = "Group",
      fill = "Group"
    ) +
    theme_classic() +
    theme(legend.position = "bottom")
}

A continuous Cox proportional hazards model on \(\log_2(\text{TMB} + 1)\) shows that higher Tumor Mutational Burden is significantly associated with a lower hazard of death for the whole cohort and therefore better overall survival (\(\text{HR} = 0.75\), 95% CI: \(0.64\text{-}0.88\)). The proportional hazards assumption is not violated (\(p = 0.38\)), supporting a consistent protective association across follow-up time and reinforcing our Kaplan-Meier findings without relying on a single cutoff.

However, when fitting the continuous Cox model separately within responders (df_r) and non-responders (df_nr), the 95% confidence intervals include \(1\) in both subsets. This indicates no statistically significant continuous association between \(\log_2(\text{TMB} + 1)\) and overall survival within either response group alone, likely reflecting the small sample sizes and event counts per subgroup (as well as reduced contrast once stratified by response status), and therefore warrants cautious, exploratory interpretation rather than a definitive within-group conclusion.

Within responders (\(n = 61\): 50 high-TMB and 11 low-TMB), only 4 events occurred in total (2 per group), with the two events in the low-TMB group appearing earlier than the two events in the high-TMB group. Because event counts are so sparse - and the 95% CI already spans \(1\) - the proportional hazards test (cox.zph \(p = 0.038\)) should be interpreted cautiously as a sign that the subgroup model is underpowered/unstable rather than a robust standalone finding.
